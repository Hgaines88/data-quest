# DQ-25 stakeholder exploration

## Audience and decision boundary

The primary user is a **Director of Economic Strategy at a national consulting
firm**. The workspace helps that user identify historical population context,
find each governed productivity series' highest sum across its available
Q01-Q04 observations, and inspect whether selected first-quarter observations
have a same-year population match. It supports exploration and client-question
preparation; it does not claim causality, forecast future conditions, or
compare unlike measures as if they shared units.

The stakeholder should be able to answer four plain-language questions:

1. What were mean United States population and population standard deviation
   across the complete 2013-2018 range?
2. For every governed BLS series, which year has the highest Q01-Q04 sum?
3. Which series have no quarterly observations available for selection?
4. For `PRS30006032`, what is the Q01 value by year, and is a same-year United
   States population value available?

## Governed semantic surface

Every dashboard or Genie answer must use the checked-in queries under
[`sql/stakeholder/`](../sql/stakeholder/README.md). They read only the three
published Gold contracts and preserve their grains:

| Dataset | Grain | Important semantics |
| --- | --- | --- |
| `population_summary` | One inclusive year-range row | `population_stddev` is population, not sample, standard deviation |
| `bls_best_year_by_series` | One row per governed series | Null best-year fields and `false` preserve series without usable quarters |
| `q01_population_context` | One selected series and year | Population is nullable; `population_match_found` makes absence explicit |

## Focused AI/BI dashboard specification

Create an AI/BI dashboard named **US Productivity Insight Workspace** with:

| Widget | Dataset and fields | Display contract |
| --- | --- | --- |
| Mean US population, 2013-2018 | `population_summary.mean_population` | KPI card; people; integer/grouped formatting |
| Population standard deviation | `population_summary.population_stddev` | KPI card; people; label explicitly says population stddev |
| Coverage definition | range, count, semantics | Text or one-row table showing 2013-2018, six years, population semantics |
| Best year by available quarterly sum | all `bls_best_year_by_series` fields | Searchable table; keep the selected year's observation count and unavailable series visible |
| Q01 with population context | all `q01_population_context` fields | Table with year, Q01 value, nullable people count, and match flag |
| Interpretation boundary | dashboard text | “BLS Q01 values and population are different units. Proximity or co-movement is not evidence of causation.” |

Do not place raw BLS Q01 values and population on one shared numeric axis.
Recommended filters are series label, best year, observation year, and quarterly
availability. Preserve nulls rather than replacing them with zero.

Place this visible source note on the canvas:

> Source: governed Gold tables derived from BLS productivity data and Data USA
> population data. Values reflect the latest successful Gold update verified by
> the operator. Freshness is operator-verified; automated monitoring is not yet
> enabled.

## Genie configuration

If the workspace supports editable Genie instructions, use these boundaries:

- Answer only from the three stakeholder Gold datasets.
- State units and the row grain in every quantitative answer.
- Treat missing population and absent quarterly observations as unknown or
  unavailable, never zero.
- Describe historical associations only; do not infer causality or forecasts.
- For “best year,” say that Gold ranks the sum of available Q01-Q04
  observations, state the selected year's observation count, and explain that
  ties resolve to the earliest year. Do not imply four-quarter completeness.
- When asked outside this scope, say the governed data cannot answer it.

Starter questions:

- “What were average US population and population standard deviation from 2013
  through 2018?”
- “Which year was best for PRS30006032, and how many quarters support it?”
- “Which series do not have quarterly observations?”
- “Show the Q01 and population context for PRS30006032 in 2013 and 2024.”

If Free Edition exposes only autogenerated dashboard Genie and does not expose
editable instructions, record that limitation. Do not claim custom instructions
were deployed; validate the same starter questions against the visible widgets.

## Manual Databricks build and acceptance gate

1. Pull the reviewed DQ-25 branch into the Databricks Git folder and confirm the
   most recent Gold pipeline update succeeded.
2. Add the three SQL files under `sql/stakeholder/` as dashboard datasets. If
   the deployment uses another catalog or schema, retarget all three uniformly.
3. Build the widgets, filters, definitions, units, boundary text, and source
   note above. Configure Genie where supported.
4. Run `sql/stakeholder/validate_stakeholder_values.sql`. Require exactly four
   rows and `passed = true` for every row.
5. Compare the dashboard values and at least two representative Genie answers
   with the validation output and their Gold tables.
6. Capture privacy-safe screenshots that show the title, source note, units,
   filters, representative values, and successful four-row validation. Exclude
   account identifiers, credentials, and workspace URLs.
7. If Git-folder dashboard serialization is available, export and review the
   `.lvdash.json` draft. Publishing and schedules remain workspace state and
   must be documented separately.

**DQ-25 is not complete until the live dashboard exists, the reconciliation
query passes, representative answers reconcile, and evidence is recorded.**
Repository assets alone do not satisfy that gate.

The completed live validation is recorded in
[`docs/evidence/dq25_stakeholder_exploration_validation.md`](evidence/dq25_stakeholder_exploration_validation.md).
